GPT-6 Cyber 發布，存取限於經驗證的資安團隊

OpenAI 推出用於授權資安工作的 GPT-6 Cyber，可協助尋找、驗證漏洞與提出修補。模型透過 Daybreak Red 限制存取，需要身分驗證及組織安全要求，並非所有 ChatGPT 使用者都能直接啟用。

AI 實用情報02 / TOOLS & MODELS

Claude 可串接財務帳戶，但只讀資料、不動資金

Personal Finance 在美國向 Pro、Max、Ultra 方案逐步開放測試。使用者透過 Plaid 連接帳戶後，可詢問餘額與交易、整理支出；Claude 不會轉帳、管理或投資你的資金。

值得注意這是 AI 直接理解個人資料的一個具體案例。對臺灣讀者，目前先看清使用邊界即可，不必把美國測試誤認成全球已開放。

目前僅限美國且為逐步推出的測試功能；回答仍可能有誤，重要數字需回到銀行紀錄確認。

AI 開發與技術03 / BUILD & CREATE

Claude 企業安全更新：在提示與工具呼叫前檢查政策

Claude Enterprise 的 inference hooks 正式開放，可將提示與執行前的工具呼叫交給企業安全工具檢查。另有測試中的安全中心，集中比對組織設定與 Anthropic 建議設定。

值得注意讓 Agent 接近真實工作時，除了最終答案，執行前的政策檢查與設定可見性也很重要。這些控制讓企業有機會把既有安全規則接進 AI 流程。

正式開放與測試中的功能須分開看；安全中心是設定指引，不是合規認證，也不是安全保證。

AI 實用情報04 / TOOLS & MODELS

GitHub PR 新總覽，把「還差什麼才能合併」移到最上方

GitHub 開放自願加入的 Pull Request Overview 公開預覽，將合併準備狀態、檢查與下一步放到頁面頂部，也提供未解決討論篩選與最新留言排序。

值得注意如果你常讓 AI 開分支、提交修改，這種集中顯示阻礙的介面，能減少在長串留言中來回尋找檢查結果的時間。

目前是公開預覽，分批推出；可從 PR 頁首選擇試用，也可切回原本介面。
