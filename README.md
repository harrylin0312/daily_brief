# Daily Brief｜每日科技快報

給自己閱讀的繁體中文科技日報：只留下真正重要的資訊，適時配圖，不為了湊篇數增加內容。

## 目前狀態

目前網站是純 HTML／CSS 概念展示，尚未完成真實新聞的產製、歷史期數與自動部署流程。已建立本機 Codex 每日排程；排程已設定不等於網站自動發布已驗證。本次文件更新用來先驗證本機提交與 GitHub 推送流程。

## 內容與閱讀體驗

- AI 實用情報：模型、工具、新功能與重要價格變動。
- AI 開發與技術：開發工具、Agent、開源模型、本機 AI 與重要研究。
- 科技與產業大事：科技公司、晶片、硬體及重大政策。
- 三類各自精選，不設最低篇數；全球來源、繁體中文整理，優先官方與原始資料。
- 每則保留來源連結、發布日期、精簡重點與值得注意的原因；合併同事件並避免重複刊登。
- 依內容使用可合法使用的官方圖片、資訊圖或明確標示的 AI 概念插圖，不強制每則配圖。
- 重新設計電腦與手機閱讀介面，不受現有展示版樣式限制；正式版本需保留歷史期數。

## 自動發布守則

1. 先確認正式副本、origin、分支及遠端同步狀態；只在乾淨且可快轉時更新本機。
2. 保留使用者未提交修改，只明確暫存本次相關檔案，不自動 stash、不清除檔案、不強制推送。
3. 每個臺灣日期只對應一期；重跑不得重複刊登或製造空提交，避免多次執行同時發布。
4. 發布前檢查日期、來源、內容結構、資產連結、敏感資料與手機／電腦呈現；必要檢查通過才更新正式首頁。

6. 來源擷取失敗與沒有重要新聞必須區分。圖片失敗可改用文字；關鍵驗證失敗則保留上一期，停止本次發布並回報。
7. Git 衝突不得覆寫使用者工作；push 被拒絕先檢查遠端，不強推。
8. 分別確認本機產出、commit、push 與網站部署；未驗證上線時不得宣稱發布成功。
9. 不提交金鑰、環境變數檔、帳務資料、個人檔案與快取。
