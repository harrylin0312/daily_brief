Azure APIM Classic 漏洞遭利用，封堵入口後仍須輪替密鑰

收錄於 2026-11-25 日報 · NSM 官方警報（11/20發布、11/23更新）

已確認的事

  • BleepingComputer 23 日取得微軟直接確認與客戶通知：APIM Classic 的 Developer、Basic、Standard、Premium 受影響，Consumption 與 APIM v2 不受影響；18 日發現、19 日封堵未授權管理存取路徑。
  • 可能暴露 Named Values 機密、身分／OIDC 供應者 client secrets、subscription keys 及管理 API tokens。NSM 官方指出未知攻擊者主動尋找這些資料，要求輪替並盤點後端；其版本指引與微軟稱雲端已全面部署修正之間的差異，報導尚未釐清。

影響與限制

  • 先核對租戶通知、輪替相關憑證及調查可存取的後端。NSM 的修補檢查門檻為 0.52.x 尾碼至少 31936、0.53.x 至少 31938；其他版本格式不能直接套用。 NSM 仍未確定利用規模；微軟原始通知非公開，本則區分官方 NSM 與媒體取得的微軟說法，不宣稱所有 Azure 客戶都已外洩。
