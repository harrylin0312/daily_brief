GitHub LFS 約三小時降級已恢復，一般 Git 操作未受影響

收錄於 2026-11-27 日報 · GitHub官方LFS事故報告

已確認的變化

  • GitHub官方事故報告指出，LFS於25日21:30至26日00:28 UTC降級，對應臺灣26日05:30至08:28；平均2%、最高4%的LFS請求失敗，更多請求先失敗後自動重試成功，造成傳輸變慢。
  • 單一區域LFS伺服器被大量自動、未驗證流量壓垮；官方將流量移至其他容量較足區域，00:28恢復正常錯誤率、00:43宣布結案。其他Git操作未受影響，勿與前一場多產品事故混淆。

為何重要與限制

  • 大型素材與模型檔案流程應核對LFS傳輸結果和重試，不應僅因一般程式碼能推送就認定大檔案也完成。 未公布受影響用戶總數；官方未將流量事件定性為已確認攻擊，不另行推論。
