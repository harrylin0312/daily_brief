@GitHub 在 Slack／Teams 正式開放，聊天可接上 issue 與 PR

收錄於 2026-11-08 日報 · GitHub 官方更新

這次正式開放什麼

  • GitHub 11 月 6 日宣布 Slack／Teams 的 @GitHub 整合正式開放，可從對話調查 bug、建立 issue、實作修改與開啟 PR；不是替所有 PR 自動合併。

協作上的具體變化

  • Teams Canvas 可並看實作計畫、程式變更與預覽；服務可從訊息辨認儲存庫。由對話建立的 issue 和 PR 也會標示對話來源與使用者，方便追溯。

使用前先確認

  • 先確認團隊的 Slack／Teams 連接、GitHub 登入及儲存庫存取權。依原有審查規則驗證變更；公告沒有表示所有方案免費，也沒有取消專案權限。
