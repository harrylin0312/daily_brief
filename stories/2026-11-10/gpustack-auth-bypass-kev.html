SECURITY / THE ESSENTIALS

重大資安漏洞原文 2026-07-31 · 約 1 分鐘讀懂

GPUStack 管理員驗證繞過已遭利用，升級至 2.2.0

收錄於 2026-11-10 日報 · GPUStack 官方安全公告

新進展與影響

  • CISA 11 月 9 日新增 CVE-2026-102895。GPUStack 官方公告列出受影響版本低於 2.2.0，並記錄過 2.1.1 部署遭實際利用。
  • 問題在於把本機來源視為可信任管理員；反向代理等配置可能使外部請求被錯誤信任，進而暴露使用者、模型、金鑰與工作節點。

修補與檢查

  • 升級至 2.2.0 或更新版本；無法立即升級時，官方建議強制本機來源也須驗證、限制 API 網路暴露並檢查代理的來源標頭處理。
  • 若懷疑已受侵害，檢查非預期管理 API 金鑰、自訂後端與節點活動，評估撤銷外洩憑證。公告早於本期，重點是已知遭利用風險提升，不是今天才發現漏洞。
