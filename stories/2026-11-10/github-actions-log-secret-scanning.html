GitHub 開放 Actions 日誌密鑰掃描預覽，須企業手動啟用

收錄於 2026-11-10 日報 · GitHub Changelog

它做什麼

  • 工作流程執行完成後，GitHub 依供應商密鑰模式掃描日誌；發現項目出現在儲存庫 secret scanning 警示列表，可連回原日誌，刪除日誌後警示仍保留。

啟用前先看限制

  • 公開預覽限 GitHub Enterprise Cloud 且具 Secret Protection 或 Advanced Security 授權，包含 GHE.com 資料落地企業。企業擁有者須在安全政策手動啟用，儲存庫本身也須符合密鑰掃描條件。
  • 只掃啟用後完成的執行，不回溯；不涵蓋通用、自訂、AI 偵測模式或 Actions 已遮罩的密鑰。預覽警示不發通知，應主動查看列表並處理外洩憑證，不能期待它即時阻止輸出。

A LITTLE LESS NOISE

資訊很多，值得讀的就好。

全球科技與 AI、投資市場、重大資安漏洞、F1。由 Codex 蒐集、查核並整理，只挑重要的，不要求每類每天都有消息。先看重點，有興趣再了解更多。

我們如何選題與使用圖片

優先官方公告、開發文件與原始研究，依實際影響與新資訊選題。同事件合併，未確認消息不當作事實。市場資訊標明時間與比較基準，資安資訊以影響與修補為重點，F1 排除未確認傳聞。數據圖保留出處，AI 概念圖不當作事件照片。關鍵查核失敗則不發布新刊；重要決策請回到原文核對。
