重大資安漏洞原文 2026-11-18 · 約 1 分鐘讀懂

Java4Shell 需優先修補，但不是所有 Java 環境都同樣暴露

收錄於 2026-11-19 日報 · CERT-EU 安全公告

已確認的重點

  • CVE-2026-114938 影響 HotSpot JVM 的 Base64 解碼。CERT-EU 說明需同時具備指定 AVX-512／BMI2 等 x86-64 CPU 功能、啟用對應 intrinsic，並有攻擊者可控資料進入解碼器；ARM64 不受此問題影響。
  • CERT-EU 列出的修復版包括 Java 17.0.21.1、21.0.13.1、25.0.5.1、27.0.1.1；8u511-perf 對應 8u513。其他 OpenJDK 發行版與內嵌 Java 的產品，仍須核對各供應商更新。

影響與限制

  • 優先盤點網際網路可達應用、容器及產品內附 runtime，完成更新並重啟所有 JVM。暫時緩解也需重啟，且可能影響效能；本期不刊攻擊操作。
  • CISA 要求立即修補不等於已確認實際利用；本次 KEV 未列此 CVE，不能把可能遠端執行寫成所有 Java 系統已遭攻陷。
