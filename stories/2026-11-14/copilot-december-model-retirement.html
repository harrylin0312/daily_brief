Copilot 預告 12 月 14 日淘汰部分模型，工作流程先盤點

收錄於 2026-11-14 日報 · GitHub Changelog

生效日與範圍

  • GitHub 公告 12 月 14 日起在 Copilot 聊天、行內編輯、ask／agent 模式及程式碼補全中淘汰六款模型，包括 Claude Fable 5、Haiku 4.5、兩款 Gemini、Grok 4.6 與 Kimi K3。
  • 公告建議 Fable 5 改用 5.1、Haiku 4.5 改用 5.5；Kimi K3 替代方案尚待公布。個人 Copilot 年繳訂閱仍可使用 Haiku 4.5，不適用該項淘汰。

團隊先確認什麼

  • 先盤點固定模型的整合與日常工作流程，再確認替代模型能否在團隊政策下啟用並測試。Business／Enterprise 若採預設啟用政策，建議替代模型通常自動啟用；全域或個別停用設定仍會影響存取。
  • 這是 Copilot 平台內的淘汰日，不應延伸成模型原廠其他產品或 API 同日停止服務。遷移不只換名稱，也應檢查結果、限制與使用權限；完整名單回到原公告。
